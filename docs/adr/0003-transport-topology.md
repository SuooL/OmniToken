# ADR-0003 传输抽象:URL 目标 + SSH 拉取 + 无状态中继

状态:已采纳(2026-07-26)

## 背景

设备网络异构:部分可组网(Tailscale/EasyTier)、部分只有公网/内网可达、
部分(机器 d)只能访问某台同伴(机器 c);不是所有机器都允许安装穿透服务;
用户不一定有公网 IP 云服务器(N2)。

## 决策

1. **agent 只出站**,上报目标是一个 URL——公网/组网虚拟 IP/内网地址一视同仁;
2. **SSH 拉取**为零安装通道:服务端 rsync 远端日志目录到本地镜像再解析,
   复用用户既有 SSH 通道,远端无需任何部署;
3. **中继 = 无状态反向代理**:agent 可开 `relay_listen` 端口原样转发 ingest,
   支持链式(d→c→server);转发失败向下游透传错误;
4. 四种方式(直连/组网/中继/SSH 拉取)可任意混用,服务端不区分来路。

## 理由

需要"可达"的只有服务端一个点;中继不落盘是因为**日志文件本身就是重传缓冲**
(offset 仅在上报成功后推进,见 ADR-0004),在中继引入存储只会制造第二个事实源。

## 后果

- 任意一环断链,数据原地等待、恢复后自动补传,无丢失无重复;
- SSH 拉取通道的实时性受拉取周期限制(≥60s),Codex/Claude 目录均纳入镜像;
- 镜像不随远端删除而删除(rsync 不带 --delete),兼得历史保全(N6)。
