# ADR-0037 紧凑菜单栏主面板与相邻详情

状态：已采纳（2026-10-29，用户确认交互原型后要求实现并发布）。
修订 ADR-0014 的桌面视觉和 ADR-0017 的内容排列，不改变速度、用量或配额计算口径。

## 决策

主面板宽 420pt，保留当前已测总速度、聚合趋势、峰值/活跃占比、今日来源总量、
双窗口配额和设备摘要。来源采用纵向列表，不再在狭窄窗口内嵌套来源卡片。
来源图标、模型比例条和选中行使用品牌色；配额和连接风险使用独立语义色。
Web/desktop 继续同步 tokens.css，新增 tool-* 外观 profile，旧 Web 主题暂不迁移。
桌面不再遵循 A4 的装饰渐变及 24px 圆角要求，使用平静背景和 12px 外框。

来源模型明细、会话速度贡献/分来源趋势、设备状态在同一个 320pt 相邻窗口按选择
切换。详情按实际内容定高，超过当前显示器工作区才滚动。主窗口不因展开而移动
或变宽；详情优先左侧、无法容纳时右侧，二者均无法容纳则在主窗口中显示。

原生窗口组成一个焦点组。失焦后等待 AppKit 完成焦点转移，再检查两者是否均失焦；
只有点击组外才关闭整个组。Esc/关闭先收起详情，随后 Esc 收起主面板。主窗口由
托盘和快捷键锚定；显示器工作区边缘做位置约束。

Rust 持有窗口生命周期及最后的详情快照。详情 WebView 只接收已脱敏的 usage/live
视图，不发起第二条 SSE 或重复遥测轮询。主面板每次刷新同步详情；首次加载通过
快照读取补上监听建立前的事件。已保存的令牌仍不返回 WebView。

配额的每个窗口独立显示百分比、进度条、tokens 余量和重置倒计时。70% 起黄，80%
起橙，90% 起红；正常为青绿。超过 100% 保留真实读数，但条长不超出轨道。缺失
使用「暂无/暂无估算」，不提供带 0 值的进度条。官方窗口已满时余量为 0，5h
可用余量仍受周余量约束。没有额外配额说明展开页。

## 验证与交付

几何与焦点决策单测、现有配额边界回归、真实生产 DOM 的浏览器 IPC fixture 检查，
加 make check、make desktop-check 和实际签名 Tauri bundle 构建。CI 在原有 Go
门禁外增加 macOS desktop-verify，自动合并必须等待两者。

浏览器 fixture 验证的是生产前端与 IPC 契约，不声称覆盖真实 AppKit 焦点行为。
本次浏览器检查不覆盖真实 AppKit 焦点行为；最终用户通过正式更新包验收。
